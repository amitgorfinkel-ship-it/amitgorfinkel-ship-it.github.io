Privacy policy

Last updated: November 16, 2026

clipper is a personal tool used only by its owner to upload short clips to the owner's own YouTube channel.

What data it accesses

With the owner's permission, through Google's OAuth sign-in, clipper uses the YouTube Data API and YouTube Analytics API to upload videos to the owner's channel and to read view, like and watch-time numbers for those videos.

How the data is used and stored

The data is used only to decide which kinds of clips perform best. The sign-in token and the numbers are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising.

Google API Services

clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also removes it.
